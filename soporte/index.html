Centro de Notificaciones & Eventos Autónomos

Flujo Event-Driven: Notificación → Agente Paiton Autónomo

Motor Autónomo Activo en esta Maqueta:
Cada vez que un usuario evalúa con 1★ o 2★ o envía pines desde el visor, el sistema despacha un evento hacia ti@compai.cl, ejecuta el analizador semántico de Agente Paiton, aplica los parches sobre la maqueta navegable y suma automáticamente la siguiente Instancia Corregida.
Arquitectura de 4 Pasos para Producción (Costo $0 / Serverless)
  1. Disparo de Evento (Cliente): Al registrar pines o evaluación 1–2★, se dispara un POST JSON con las coordenadas (xPct, yPct), vista screenIdx y notas en texto plano.
  2. Notificación Transaccional (ti@compai.cl): Una Edge Function (Supabase / Cloudflare Workers) envía alerta inmediata vía SMTP ti@compai.cl con el resumen de pines.
  3. Ejecución Autónoma (Agente Paiton / Claude Code Headless): El agente recibe el JSON, modifica el código HTML/CSS de la maqueta en el repositorio/bucket y genera el diff técnico.
  4. Callback de Publicación: El agente llama al endpoint de retorno, suma la Instancia #N+1 en estado En Revisión y notifica al cliente para su evaluación 1–3★.
