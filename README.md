# compai.cl

Página de servicio de **COMPAI GLOBAL SOLUTIONS SpA**. Un solo archivo, sin
dependencias externas.

Se publica por GitHub Pages. El archivo `CNAME` es lo que le dice a GitHub qué
dominio sirve — no se borra ni se renombra.

**`index.html` se genera.** La fuente vive en `kri-eit/sitio-compai/_construir.py`;
editar acá a mano se pierde en la siguiente construcción.

## Diseño

`diseno/wireframe.html` es el wireframe técnico de la plataforma (retícula,
componentes, flujo y siete pantallas anotadas). Es un documento de trabajo, no
parte del sitio publicado: se abre con doble clic, no se enlaza desde `index.html`
y va con `noindex`.
